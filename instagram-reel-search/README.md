# Instagram Reel Search

外部API・トークン・課金なしの個人向けリール発掘補助アプリです。

## 1画面・自動判定仕様

検索日は「今日」で自動固定し、入力欄を減らしています。

必須条件:
- フォロワー 10,000人以上
- 総投稿数 180投稿未満
- 今日から7日以内の投稿

操作:
1. #ハッシュタグからInstagramを開く
2. 候補のフォロワー数と総投稿数を入力
3. 「今日〜7日前」のボタンを押す
4. 必須3条件を自動判定
5. 通った候補だけ再生数を入力
6. 再生数 ÷ フォロワー数 >= 3 なら保存

## 数字入力

以下のような日本語表記にも対応:
- 1.2万 -> 12,000
- 3.5万 -> 35,000
- 12,500 -> 12,500

## URL

InstagramからPWAへ共有できた場合はURLを自動入力します。
手動貼り付けも可能です。
3倍条件をクリアした投稿を保存する時だけURLが必須です。

## 保存

条件一致した投稿は端末のlocalStorageへ保存します。
CSV出力、URLコピー、個別削除、全消去に対応しています。
