# Instagram リール自動発掘（ブラウザ拡張版）

Instagramにログイン済みのブラウザ上で、検索タグのリール候補を順番に確認し、4条件をすべて満たした投稿だけを一覧に残す個人利用向けツールです。

## 必須条件

- フォロワー 10,000人以上
- 総投稿数 180投稿未満
- 投稿日 7日以内
- リール再生数 ÷ フォロワー数 >= 3.0

取得できない項目が1つでもある投稿は合格扱いにしません。

## 使い方

1. PCのChromeまたはEdgeでこのリポジトリをダウンロードします。
2. `instagram-reel-auto-finder-extension` フォルダを取り出します。
3. Chromeなら `chrome://extensions/`、Edgeなら `edge://extensions/` を開きます。
4. 「デベロッパーモード」をONにします。
5. 「パッケージ化されていない拡張機能を読み込む」を押します。
6. `instagram-reel-auto-finder-extension` フォルダを選択します。
7. Instagramへ通常どおりログインします。
8. Instagram画面右下の「発掘」ボタンを押します。
9. `加工 DIY 工具` のように検索タグを登録して「自動発掘スタート」を押します。

## 動作

- 指定タグのInstagramハッシュタグページへ自動移動
- 表示されるリールURLを収集
- リールページから再生数・投稿日時・投稿者名を取得
- 投稿者プロフィールからフォロワー数・総投稿数を取得
- 4条件を自動判定
- 合格したリールだけ一覧表示
- 合格URLを一括コピー可能
- 複数タグを順番に自動処理

## 個人情報・認証

- Instagramのパスワードを保存しません。
- 外部APIトークンを使いません。
- Apifyなど外部スクレイピングサービスへ情報を送信しません。
- Instagramにログイン済みのブラウザセッション内で処理します。

## 注意

Instagram側のHTMLや内部データ形式が変更されると、再生数・投稿日時・フォロワー数・投稿数の取得ができなくなる場合があります。その場合は `content.js` の解析部分を更新する必要があります。

また、Instagramが短時間の連続アクセスを制限することがあるため、1タグの確認数は20〜40件程度から試す想定です。

## Androidについて

通常のAndroid版ChromeはChrome拡張機能を読み込めないため、この自動版はPCのChrome/Edge向けです。スマホだけで完全自動にする場合は、別途Androidネイティブ版など別方式が必要です。
