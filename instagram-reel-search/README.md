# Instagram Reel Search

Instagramリールの候補を、指定条件で絞り込むスマホ向けWebアプリです。

## 完全無料版
有料API・外部スクレイピングサービスは使用しません。

Instagram側の検索画面を開き、見つけた候補リールの公開情報をアプリに入力して、端末内で条件判定します。

## 判定条件
- フォロワー: 10,000人以上
- 総投稿数: 180投稿未満
- 1投稿の再生数: 投稿者フォロワー数の3倍以上
- 投稿日: 検索日から14日以内
- 優先表示: 7日以内
- 判定式: リール1本の再生数 ÷ 投稿者フォロワー数

## 使い方
1. ハッシュタグを入力
2. 作成されたInstagram検索リンクを開く
3. 候補リールのURLをコピー
4. URL・フォロワー数・投稿数・そのリール1本の再生数・投稿日を入力
5. 「条件で判定する」を押す
6. 条件に合ったリールだけ、投稿URL付きで一覧表示

複数URLをまとめて候補へ追加することもできます。

## 検索結果
- 投稿URLをそのまま表示
- 投稿を開く
- URLをコピー
- 7日以内を優先
- 倍率順
- 新しい順
- CSV保存

## 制約
Instagram公式APIだけでは、第三者アカウントのリール再生数・フォロワー数・投稿数を、この用途で完全自動収集することはできません。
そのため無料版では「候補探しはInstagram」「計算・絞り込み・URL整理はこのアプリ」という構成にしています。
