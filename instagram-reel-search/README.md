# Instagram Reel Search

Instagramリールを指定条件で絞り込むスマホ向けWebアプリです。

## 判定条件
- フォロワー: 10,000人以上
- 総投稿数: 180投稿未満
- 1投稿の再生数: 投稿者フォロワー数の3倍以上
- 投稿日: 検索日から14日以内
- 優先表示: 7日以内
- 判定式: リール1本の再生数 ÷ 投稿者フォロワー数

## 自動検索
外部取得サービス（Apify）を利用し、次の2段階で公開データを照合します。

1. ハッシュタグから最近のリールを取得
2. 各投稿者のフォロワー数・投稿数を取得
3. リール1本ごとの再生数と投稿者フォロワー数を結合
4. 指定条件でフィルター
5. 7日以内を優先し、倍率順・新しい順でも並び替え可能

APIトークンはソースコードやGitHubには保存しません。保存を選んだ場合のみ、そのブラウザのlocalStorageに保存します。

## 注意
Instagram公式APIだけでは、第三者アカウントのリール再生数をこの用途で安定して取得できないため、自動検索は外部の公開データ取得サービスを利用する構成です。サービス側の仕様変更やInstagram側の表示変更により取得できない場合があります。
