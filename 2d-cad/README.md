# 2D CAD かんたん作図

加工現場向けの、スマホでも直感的に使える簡易2D CADです。
単位は mm。最終的に3D CADへ展開できるデータ構造を目指します。

## 現在の機能 v0.4
- 直線
- 四角
- 円
- 長穴
- タップ作図
- 数値による正確な作図
- 寸法表示
- 図形選択
- ドラッグ移動
- 選択図形の数値修正
- 選択削除
- Undo / Redo
- 1 / 5 / 10 mm スナップ
- 拡大 / 縮小 / 全体表示
- 端末への自動保存
- JSON 読込 / 出力
- DXF 出力
- サンプル: 100×50板 + Ø10穴×2
- PWA / オフライン対応の基礎

## 保存方針
作図データは端末内へ自動保存します。
JSONでバックアップでき、DXFで一般CADへ渡せます。

GitHubの認証トークンをブラウザ内へ埋め込む方式は採用しません。
GitHub側にはアプリ本体とサンプルデータを保存します。
