# 2D CAD かんたん作図

加工現場向けの、スマホでも直感的に使える簡易2D CADです。
単位は mm。最終的に3D CADへ展開できるデータ構造を目指します。

## 現在の機能 v1.2
- 直線
- 四角
- 円
- 円弧（3タップ / 数値入力）
- 長穴
- 穴専用ツール
- M3 / M4 / M5 / M6 / M8 / M10 / M12（並目）の代表的なタップ下穴径を自動設定
- ザグリ穴・皿穴（外径任意入力）
- 数値による正確な作図
- 寸法表示
- 図形選択
- ドラッグ移動
- 選択図形の数値修正
- 選択削除
- 直線同士のトリム
- オフセット（直線 / 四角 / 円 / 穴 / 長穴 / 円弧）
- 四角の角への面取り C
- 四角の角へのR
- コピー（X/Y移動量指定）
- ミラー（X/Y基準線指定）
- 回転コピー（四角形は90°単位）
- 手動寸法線（3タップ）
- 寸法方向: 平行 / 水平 / 垂直
- パン操作（手のひらツール）
- レイヤー選択 / 表示・非表示
- 複数選択 / 一括移動 / 一括削除
- Undo / Redo
- 1 / 5 / 10 mm スナップ
- 拡大 / 縮小 / 全体表示
- 端末への自動保存
- JSON 読込 / 出力
- DXF 読込（LINE / CIRCLE / ARC / LWPOLYLINE）
- DXF 出力
- SVG出力（図枠・タイトル付き）
- 印刷 / PDF保存用ビュー
- 図面名 / 図番 / 尺度 / 作成者の図枠設定
- サンプル: 100×50板 + Ø10穴×2
- PWA / オフライン対応

## スマホUI v1.2
- 作図キャンバスと操作バーを完全分離
- 下側に作図専用領域、右側に編集専用領域を確保
- 座標・図形と操作アイコンが重ならないレイアウト
- レイヤーアイコンも右側編集領域へ移動

## スマホUI v1.0
- 作図ツールを画面下へ配置
- 編集ツールを画面右へ配置
- スナップ機能を廃止し、指で自由に配置
- レイヤーを独立ボタン化（0〜10）
- 削除アイコンを編集ツールへ常設
- 削除アイコンの選択解除不具合を修正
- 2本指ドラッグで画面移動
- ピンチ操作で拡大 / 縮小
- 2D画面では専用ズームボタンを廃止
- オンライン時は最新版を優先して読み込むキャッシュ方式

## 保存方針
作図データは端末内へ自動保存します。
JSONでバックアップでき、DXFで一般CADへ渡せます。

GitHubの認証トークンをブラウザ内へ埋め込む方式は採用しません。
GitHub側にはアプリ本体とサンプルデータを保存します。
