# Instagram Reel Search

外部API・トークン・課金なしの個人向けリール発掘補助アプリです。

## 必須条件（固定）
- フォロワー 10,000人以上
- 総投稿数 180投稿未満
- 投稿日は検索日から7日以内

この3条件をすべて通った候補だけ、次の再生数判定へ進みます。

## 2段階判定
1. 検索日（初期値は今日）を確認
2. リールURL、フォロワー数、総投稿数、投稿日を入力
3. 必須3条件を判定
4. 通過した候補だけ再生数を入力
5. 再生数 ÷ フォロワー数 >= 3 を判定
6. 3倍以上だけ端末内へ保存

## 検索日の判定
- 検索日を基準に、投稿日との差が0〜7日だけ通します
- 例: 検索日が9/28なら9/21〜9/28が対象です
- 検索日より後の投稿日は対象外です

## 検索
- #ハッシュタグからInstagramのタグページを開く
- Instagram側で候補リールを探す
- 外部スクレイピングサービスは使用しない

## Android共有
PWAとしてホーム画面に追加した場合、Web Share Target対応ブラウザ/OSではInstagramの共有URLをアプリへ受け取れるようにしています。

## 保存
条件一致した投稿はlocalStorageに保存します。
CSV出力、URLコピー、個別削除、全消去に対応しています。
