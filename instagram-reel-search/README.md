# Instagram Reel Search

最初のシンプル仕様に戻した、完全無料のスマホ向けリール判定アプリです。

## 初回設定
不要です。

## 判定条件
- フォロワー: 10,000人以上
- 総投稿数: 180投稿未満
- 1投稿の再生数: 投稿者フォロワー数の3倍以上
- 投稿日: 14日以内
- 優先表示: 7日以内
- 判定式: リール1本の再生数 ÷ 投稿者フォロワー数

## 使い方
1. 候補リールのURLを入力
2. フォロワー数を入力
3. 投稿数を入力
4. そのリール1本の再生数を入力
5. 投稿日を入力
6. 「条件で判定する」を押す

条件に合った投稿だけ、URL付きで一覧表示されます。

## 機能
- 7日以内優先
- 倍率順
- 新しい順
- 投稿を開く
- URLをコピー
- CSV保存

有料API、Meta Access Token、Facebookページ連携は不要です。
