# AI 3D Maker

カードやイラストの画像から立体表示を作るスマホ向けPWAです。

## v0.2
- JPG/PNG画像読込み
- Three.jsによる3D表示
- 指で回転・ズーム
- 簡易深度から2.5Dメッシュ生成
- 実験的AI深度推定（DPT/MiDaS系、端末内推論）
- PNG保存
- GLB保存
- PWA対応

## 現在地
v0.2 は「画像 → 深度 → 3Dメッシュ」まで実装済みです。
GLBとして3Dファイル出力できます。

ただし1枚の写真だけでは、写っていない側面・背面の形状を正確には復元できません。
現在のGLBは正面深度をもとにした立体メッシュです。
