# 販売管理システム

最新版：v11 出納帳追加版

このフォルダーには販売管理システムの最新版ZIPを保存しています。

## ダウンロード
`販売管理システム_試作版_v11_出納帳追加.zip`

ZIPをダウンロードして解凍し、`index.html`をブラウザで開いて使用します。

## 主な機能
- 顧客管理
- 仕入先管理
- 売上管理
- 月次売上
- 仕入管理
- 発注管理 / 発注書発行
- 締め請求 / まとめ請求書発行
- 入金管理
- 支払管理
- 出納帳（経費精算）
  - 現金 / クレジットカード
  - 支払方法のプルダウン検索
  - 年月検索
  - 経費合計・現金合計・カード合計
- 設定・JSONバックアップ

※ 現在はブラウザ内保存の試作版です。
