# Instagram リール自動発掘 Android版

Androidスマホだけで使う個人向け自動発掘アプリです。アプリ内WebViewでInstagramへ通常ログインし、検索タグのリール候補を順番に確認して、4条件をすべて満たした投稿だけ保存します。

## 必須条件

- フォロワー 10,000人以上
- 総投稿数 180投稿未満
- 投稿日 7日以内
- リール再生数 ÷ フォロワー数 >= 3.0

1項目でも取得できない場合は合格扱いにしません。

## 使い方

1. APKをAndroidにインストール
2. アプリ内のInstagramで通常どおりログイン
3. 上部に `#加工 #DIY #工具` のようにタグを入力
4. 1タグの確認数を10 / 20 / 30件から選択
5. 「自動発掘スタート」
6. アプリがタグページ → リール → 投稿者プロフィールを順番に確認
7. 4条件を全部クリアした投稿だけ「結果」に保存
8. 結果画面からURLを一括コピー

## 認証・外部サービス

- Apify不使用
- Meta APIトークン不使用
- 外部スクレイピングサービス不使用
- Instagramのパスワードをアプリ独自の保存領域へ記録しません
- Instagramのログイン画面とCookieはAndroid WebView側で処理します

## 注意

Instagram側のHTML表示が変わると、再生数・投稿日時・フォロワー数・投稿数の取得部分が動かなくなる場合があります。その場合は `MainActivity.java` 内のJavaScript解析部分を更新します。

短時間に大量アクセスするとInstagram側で制限される可能性があるため、まずは1タグ10件からの利用を推奨します。

## APKビルド

GitHub Actionsの `Build Reel Finder Android APK` ワークフローでDebug APKを自動生成します。成果物名は `reel-auto-finder-debug-apk` です。
