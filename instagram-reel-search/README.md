# Instagram Reel Search

無料・初回設定なしのInstagramリール判定アプリです。

## 流れ
1. #ハッシュタグを入力
2. Instagramのハッシュタグ検索を開く
3. 候補リールのURL・フォロワー数・投稿数・再生数・投稿日を入力
4. 条件判定
5. 合格した投稿URLを一覧表示

## 判定条件
- フォロワー: 10,000人以上
- 総投稿数: 180投稿未満
- 1投稿の再生数: 投稿者フォロワー数の3倍以上
- 投稿日: 14日以内
- 優先表示: 7日以内

判定式:
リール1本の再生数 ÷ 投稿者フォロワー数

## 補足
- Meta Access Token不要
- Facebookページ連携不要
- 有料API不要
- 複数URLまとめて追加可能
- 倍率順・新しい順・7日以内優先
- CSV保存対応
