# 日本候補・条件一致リール発掘 Android版

Instagramのおすすめ、または指定したハッシュタグからリール候補を集め、日本候補かつ固定条件をすべて満たした投稿だけを保存する個人利用向け試作アプリです。

実装本体は `app/src/main/java/com/arata/conditionreelfinder/MainActivity.java` です。

## 固定条件

- 日本候補として判定できること
- フォロワー 10,000人以上
- 総投稿数 180投稿未満
- 投稿日 7〜14日前（7日前と14日前を含む）
- リール再生数 ÷ フォロワー数 >= 3.0

6日前以内と15日前以上の投稿は自動で除外します。

## 検索モード

### おすすめから探す

Instagramの発見・おすすめから候補を集め、固定条件で絞り込みます。

### #から探す

`#おにぎり` のようにタグを指定して、そのタグに出てくるリール候補から固定条件で絞り込みます。

複数タグにも対応しています。

例：

`#おにぎり #弁当 #料理`

この場合は各タグを順番に検索します。候補数 10件を選んだ場合、#検索では各タグにつき最大10件を確認します。重複URLは二重に確認しません。

結果には「おすすめ」「#おにぎり」のように検索元も保存します。

## 日本候補判定

Instagramは第三者アカウントの国を常に公開しているわけではないため、GPSや公式の国コードで日本を確定する方式ではありません。

厳しめに次のどちらかで判定します。

- 投稿・プロフィールに「日本 / Japan / 東京 / 大阪 / 埼玉」など日本の地名が確認できる
- リール側とプロフィール側の両方に日本語（ひらがな・カタカナ）が確認できる

日本候補判定が取れない投稿は、その他の条件を満たしていても除外します。そのため海外候補を減らせますが、日本の投稿を一部取りこぼす場合があります。

## 使い方

1. アプリを開く
2. 「おすすめから探す」または「#から探す」を選ぶ
3. #検索の場合は `#おにぎり` などを入力する。複数タグは空白区切りで入力可能
4. 確認する候補数を 10 / 20 / 30件から選ぶ
5. 「検索スタート」を押す
6. 日本候補判定＋固定条件をすべて満たした投稿だけ「結果」に保存される

最初は10件推奨です。

検索中は設定欄を畳み、「停止」「結果」と進捗だけを上部に残します。検索完了または停止すると設定欄が再表示されます。

## 結果に表示する項目

- 検索元
- 投稿者名
- フォロワー数
- 総投稿数
- 投稿日からの日数
- 再生数
- フォロワー比
- リールURL

## 認証とデータ

- 外部APIキーは不要
- Apifyは使わない
- Instagramパスワードをアプリ独自に保存する処理は入れていない
- ログイン状態はAndroid WebViewのCookieとして保持される場合がある
- 保存領域は v4 に更新し、旧条件の結果と混ざらないようにしている

## 注意

InstagramのHTML・表示仕様が変わると、再生数・投稿日・フォロワー数・投稿数・日本候補判定用テキスト・ハッシュタグページのリールURLを取得できなくなる場合があります。取得できない項目が1つでもある候補は合格扱いにしません。

短時間に大量アクセスするとInstagram側から制限される可能性があるため、最初は10件で試す想定です。
