# AI 3D Maker

カードやイラストの画像から立体表示を作るスマホ向けPWAです。

## v0.1
- JPG/PNG画像読込み
- Three.jsによる3D表示
- 指で回転・ズーム
- 簡易深度から2.5Dメッシュ生成
- 実験的AI深度推定（DPT/MiDaS系、端末内推論）
- PNG保存
- PWA対応

## 重要
現在の v0.1 は「深度メッシュ」による2.5Dです。
1枚の写真だけでは、写っていない側面・背面を正確に復元できません。

## 次の段階
1. キャラクター自動切り抜き
2. 複数画像入力（正面/左右/背面）
3. 多視点AI画像生成
4. 3D再構成
5. GLB/OBJ出力
6. 360度完全回転
