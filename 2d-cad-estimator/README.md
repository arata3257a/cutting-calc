# 2D CAD 加工費見積版

本体の `2d-cad/` v1.34 を基準に分岐した試作版です。本体フォルダーは変更しません。

## 試作 v0.7
- 時間単価を設定
- 素材厚みで穴・ネジ穴・外形の加工時間を補正
- 掘込み深さで溝加工時間を補正
- 線・円弧・輪郭を外形加工 / 溝加工に手動指定可能
- 未指定の図形だけ自動判定し、手動指定を優先
- 円・穴を普通の穴 / ネジ穴に手動指定可能
- 同じ中心の円は1つの穴としてまとめて指定
- 見積モード中はCAD作図・編集コマンドを無効化
- キャンバスタップを見積専用の要素選択に切替（編集パネルは開かない）
- 見積対象は複数選択可能
- スマホの見積パネルを画面下側へ寄せ、高さを約45%に抑えて図形選択領域を確保
- 「穴判定 最大径」を廃止
- 未指定の円は穴として扱い、代表的なタップ下穴径に近い円だけネジ穴候補として自動判定
- 穴数を図面から自動認識
- ネジ穴をCADの穴属性、または代表的なタップ下穴径から候補認識
- 外形周長を閉じた輪郭の最大周長から推定
- 溝加工長を長穴・内側閉ループ・開いた線/円弧から推定
- 認識結果は手動修正可能
- 穴、ネジ穴、外形、溝、段取りの推定時間を合計し、時間単価から概算加工費を算出

概算用のため、材料費、工具交換、測定、治具、仕上げ、加工難易度などは未反映です。
