AI 3D Maker v2.2 - Windows 無料ローカル版

重要:
GitHub Pagesの画面だけでは3D生成できません。
3Dエンジン(TripoSR)をPCで動かす必要があります。

初回だけ:
1. setup_windows_cpu.bat をダブルクリック
2. 完了するまで待つ

使う時:
1. start_windows.bat をダブルクリック
2. 黒い画面を閉じない
3. PCでは http://localhost:8000/
4. スマホでは黒い画面に表示された http://192.168.x.x:8000/ を開く
5. 画像を選んで3D生成

料金:
外部有料API = 0円

注意:
CPU版は無料ですが、3D生成にはかなり時間がかかる場合があります。
NVIDIA GPUがあるPCなら、後からGPU版へ切り替えられます。
