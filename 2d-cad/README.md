# 2D CAD かんたん作図

加工現場向けの、スマホでも直感的に使える簡易2D CADです。

## v0.1
- 直線
- 四角
- 円
- 戻る
- 全消去
- 端末保存（localStorage）
- JSON出力
- サンプルデータ読込
- グリッド表示

## フォルダー
- `index.html` : 画面
- `style.css` : UI
- `app.js` : 描画・保存ロジック
- `data/drawing.json` : 初期サンプル図形データ

## 保存方針
アプリで作成した図形は、まず端末内（localStorage）へ保存します。
必要に応じてJSONとして出力できます。

※ GitHub Pages上のブラウザアプリからGitHubリポジトリへ直接書き込むには認証情報が必要になるため、
トークンをアプリ内へ埋め込まず、安全な保存方式を優先します。
