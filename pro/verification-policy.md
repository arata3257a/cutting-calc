# PRO 条件データ検証ルール

1. メーカー公開の切削条件表に存在する値のみ登録する。
2. 工具径は原則1mm単位（φ1, φ2, ...）。0.5mm刻み等はUIには通常出さない。
3. メーカー表にない径は補間しない。
4. N / F / ap / ae はメーカー表の値を保持する。
5. Vc / fz は N / F / 工具径 / 刃数から計算し、メーカー値と混同しない。
6. 同径でも刃長・型番で条件が異なる場合、別条件として管理する。勝手に代表値へ統合しない。
7. 材質名だけでなく、焼鈍・調質・焼入れ、HB/HRC範囲までキーに含める。
8. 加工方法（側面・溝・Z切込み・仕上げ等）はメーカー表の区分を維持する。
9. 出典メーカー、シリーズ、資料名を各データセットに保持する。
10. 公開前に代表径だけでなく登録径を全数照合する。

## HGS 初回採用
HGSは6枚刃の仕上げ条件。PRO UIは整数径のみ採用し、標準2D刃長行を径ごとの基準条件として別データセット化する。長刃長型は同径でも条件が異なるため、将来「刃長タイプ」選択を追加して別管理する。
