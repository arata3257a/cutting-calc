# 日本限定・条件一致リール発掘 Android版

キーワードやハッシュタグを入力せず、Instagramの発見・おすすめに出るリール候補から、日本候補かつ指定条件をすべて満たした投稿だけを保存する個人利用向け試作アプリです。

## 固定条件

- 日本候補として判定できること
- フォロワー 10,000人以上
- 総投稿数 180投稿未満
- 投稿日 7〜14日前（7日前と14日前を含む）
- リール再生数 ÷ フォロワー数 >= 3.0

6日前以内と15日前以上の投稿は自動で除外します。

## 日本判定

Instagramは第三者アカウントの国を常に公開しているわけではないため、GPSや公式の国コードで確定する方式ではありません。

厳しめに次のどちらかで判定します。

- 投稿・プロフィールに「日本 / Japan / 東京 / 大阪 / 埼玉」など日本の地名が確認できる
- リール側とプロフィール側の両方に日本語（ひらがな・カタカナ）が確認できる

日本判定が取れない候補は、その他の条件を満たしていても除外します。そのため海外候補を減らせますが、日本の投稿を一部取りこぼす場合があります。

## 使い方

1. アプリを開く
2. Instagram画面が表示されるのを待つ
3. Instagram側がログインを要求した場合はログインする
4. 確認する候補数を 10 / 20 / 30件から選ぶ
5. 「自動発掘スタート」を押す
6. 日本判定＋条件一致した投稿だけ「結果」に保存される

最初は10件推奨です。

結果には以下を表示します。

- 投稿者名
- フォロワー数
- 総投稿数
- 投稿日からの日数
- 再生数
- フォロワー比
- リールURL

## 検索元

- まず `https://www.instagram.com/explore/` の発見画面から候補を収集
- 候補数が足りない場合は `https://www.instagram.com/reels/` から追加収集
- キーワード、ハッシュタグは使いません

## 認証とデータ

- 外部APIキーは不要
- Apifyは使わない
- Instagramパスワードをアプリ独自に保存する処理は入れていない
- ログイン状態はAndroid WebViewのCookieとして保持される場合がある

## 注意

InstagramのHTML・表示仕様が変わると、再生数・投稿日・フォロワー数・投稿数・日本判定用テキストを取得できなくなる場合があります。取得できない項目が1つでもある候補は合格扱いにしません。

短時間に大量アクセスするとInstagram側から制限される可能性があるため、最初は10件で試す想定です。
