# AI 3D Maker v2.2

完全3Dを目指す無料ローカル版です。

## 方針
外部の有料APIは使いません。

- スマホ: 画像選択・トリミング・操作
- PC: TripoSRによる3D生成
- 出力: GLB

旧版のような「画像を板状に変形する2.5D」ではなく、TripoSRが1枚画像から3Dメッシュを生成します。

## 現在実装済み
- 画像アップロード
- トリミング
- PC側rembg背景除去
- PC接続確認
- TripoSR生成ジョブ
- 進捗取得
- GLB保存
- PWA

## 重要
スマホ単体だけで完全3D生成する構成にはしていません。
処理負荷が大きいため、PCで生成してスマホから操作する方式です。
